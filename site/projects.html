Other projects

Other firmware and instruments by Nuno Zimas. The source code of each is on GitHub.

Tonitor

M-VAVE FM-1

Acousmatic firmware for electroacoustic experimentation, live ambient music and sound exploration: six tracks, eight synthesis engines, loopers and sequencers. Molecular's generator is Tonitor's FM engine, and its families of sounds are Tonitor's and more. Installed from the browser, over USB MIDI.

Website GitHub repository

Norilsk

M-VAVE FM-1

Firmware for dark ambient, harsh drones and noise. Three generators, each drawn at random and routed through its own chain of effects drawn at random. Molecular's atoms are Norilsk's effects. Installed from the browser, over USB MIDI.

Website GitHub repository

Bigorna

M-VAVE FM-1

Firmware for rhythmic noise, power noise, power electronics and IDM, with the Elektron Digitone II as its reference: six tracks, four machines, a 16-step sequencer with parameter locks and trig conditions. Installed from the browser, over USB MIDI.

Website GitHub repository

Tonitor for the SMK-37 Pro

M-VAVE SMK-37 Pro

Tonitor for the M-VAVE SMK-37 Pro keyboard: six tracks, eight synthesis engines, loopers and sequencers.

Website GitHub repository

SteamRoller

Novation Circuit Rhythm

Firmware for rhythmic noise, IDM and experimental percussion: a drum sound generator, Elektron-style parameter locks, and the Grid FX locked to single steps of single tracks.

Website GitHub repository

Motor:Cycles

Elektron Model:Cycles

Firmware for rhythmic noise and power noise: generative algorithms build sounds, kits, phrases and patterns, installed with a browser patcher that modifies your own copy of the official firmware.

Website GitHub repository

DigiRust

Elektron Digitone II

Firmware tools for IDM, rhythmic noise, power noise and electroacoustic music: a browser patcher and a macOS app that create a modified copy of the official Digitone II OS on your computer.

Website GitHub repository

Vascular

iOS · Android

A canvas-based electroacoustic instrument for phones and tablets: sound generators and processors placed and connected by touch, the network the signal path. Its Angiogenesis changes the network on its own; Molecular's motion takes its idea from it.
